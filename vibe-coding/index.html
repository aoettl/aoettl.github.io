Set up an AI coding agent

You have probably asked ChatGPT or Claude to make something in a chat window, such as a quiz or a chart. A coding agent differs because it works on your own computer within a folder that you choose. It can read the files in that folder, and it runs the programs it writes and fixes them when they fail. The programs stay in the folder, so you can run one again next month on new data.

Building software by describing what you want in plain English is often called vibe coding, and it requires no programming experience. Installing an agent and building a first program takes about 45 minutes. Once you choose your computer and your tool below, the page shows only the steps for that setup.

I wrote this page for students in my Emory BBA Strategy course. The steps follow each AI company's own instructions as of November 2026, and because these apps change frequently, some information may be outdated.

Tools

You need only one of the three tools below. If you already pay for ChatGPT, Claude or Gemini, use the tool from your subscription. If you don't currently pay for any, I'd consider signing up for the free Google AI Pro student plan, which includes access to Antigravity. Google requires a credit card when you sign up and charges $19.99 a month after the free year unless you cancel, so set a reminder! The offer ends December 31, 2026.

Setup

Setup takes about 20 minutes, and you do it only once.

Install Python

The agent writes its programs in Python, a free programming language, and needs Python installed on your computer to run them.

  1. Go to python.org/downloads and click the download button at the top of the page.

  2. MacOpen the downloaded file and click through the installer, keeping the default choices. Then open your Applications folder, open the Python folder in it, and double-click Install Certificates.command. This step lets Python download from secure websites such as sec.gov.

    WindowsRun the downloaded file and keep the default choices. If you see a box labeled Add python.exe to PATH, check it.

Install the app and sign in

Choose a tool above to see only its steps.

Antigravity

  1. Go to antigravity.google/download and find Antigravity App. The page also offers a CLI and an IDE, which you do not need.

  2. MacClick Download for Apple Silicon. If your Mac has an Intel processor, click Download for Intel. To check, open the Apple menu and choose About This Mac. A line that begins with Chip means Apple Silicon, and one that begins with Processor means Intel.

    WindowsClick Download for x64. If your laptop has a Snapdragon processor, click Download for ARM64.

  3. MacOpen the downloaded Antigravity.dmg file and drag Antigravity into your Applications folder. Then open it from Applications.

    WindowsRun the downloaded installer and follow the setup wizard. Then open Antigravity from the Start menu.

  4. Click Sign in and finish in your browser with a personal Google account.

  5. When the app asks what best describes your work, choose Knowledge Work. This gives you a simpler screen that hides the controls programmers use. Then accept Terms & Data Use.

Open a folder

The agent works inside a single folder. Make a new, empty folder named first-build on your Desktop and open it in the app.

Antigravity

  1. Click the New Project icon in the left sidebar. It looks like a folder with a plus sign.

  2. Click Add Folder, choose first-build, then click Create.

  3. Leave the permission setting on Default, which asks you before sensitive commands.

    WindowsOn Windows 10, and on Windows 11 older than version 24H2 with the August 2026 update, Antigravity asks before every command instead. It still works, but you will approve more requests.

Codex

  1. MacClick Add new project next to Chats, or press Command-O. Choose first-build.

    WindowsClick Add new project next to Chats, or press Ctrl+O. Choose first-build.

  2. Choose Local, so that Codex works in the folder on your computer.

  3. Below the message box, set permissions to Ask for approval.

    WindowsDo this before you send your first message, because it also switches on the protection that keeps Codex inside your folder.

Claude

  1. Click the Code tab at the top of the sidebar. If the tabs show only icons, hover over one to see its name.

  2. In the row under the message box, click the first control and choose the top entry under Local.

    WindowsThe list also offers WSL, which you should not choose.

  3. Click the folder control next to it, choose Open folder…, and pick first-build.

  4. In the same row, set the permission mode to Manual. Claude then asks before it changes a file or runs a command.

Test the setup

Type this request and press Enter.

Write a Python script that prints today's date, then run it.

Approve any requests the agent makes. You should see today's date in its reply and a new file in your first-build folder, which is the program it wrote. If the agent says Python is not installed, quit the app, open it again and repeat the request.

Permissions

AntigravityOn the Default setting, Antigravity works inside your folder without asking but asks before it reaches outside it, for example to download from sec.gov or to install a Python package. The Turbo setting skips these requests and should stay off for everything on this page.

CodexOn Ask for approval, Codex works inside your folder without asking but asks before it reaches outside it, for example to download from sec.gov or to install a Python package. Full access skips these requests and should stay off for everything on this page.

ClaudeIn Manual mode, Claude asks before it changes a file or runs a command. Bypass permissions skips these requests and should stay off for everything on this page.

Read each request before you approve it.

A first program

The first program downloads ten years of a company's revenue and net income from the SEC and charts them, which takes about 15 minutes. Larger projects follow the same pattern, with the agent downloading what it needs and leaving a program in your folder that you can run again.

  1. Pick a company that files with the SEC, such as Delta or Apple. Foreign firms such as Adidas and Samsung do not file there.

  2. Paste this request, replacing the two parts in brackets.

    In this folder, write a Python program that downloads [company]'s annual revenue and net income for the last ten fiscal years, or as many years as the SEC has, from the SEC's free EDGAR API. The SEC asks for a contact email in each request; use [your email address]. Save the numbers to a CSV file and draw a line chart of both as a PNG file. Then run the program and show me the table.

  3. Approve the agent's requests as they come. It will probably hit an error or two, which it reads and fixes on its own.

  4. Open the PNG file in your folder and look at the chart yourself. The CSV file opens in Excel.

  5. Then ask for a change, such as Add United Airlines to the same chart or Change the program so it asks me which company to look up.

Check the numbers

An agent's numbers can be wrong even when its table looks clean. In two test runs for this page, an agent labeled every Nike year two years late, so its chart showed Nike's revenue at a record high in fiscal 2026, when revenue was about a tenth below its 2024 peak (the same agent got Delta right the same morning).

  1. Go to sec.gov/edgar/search, type the company's name and open its most recent 10-K, which is the annual report.

  2. Find the income statement, usually titled Consolidated Statements of Operations or Consolidated Statements of Income, and read total revenue for the latest fiscal year.

  3. Compare it with the last row of your CSV file.

If the two differ, tell the agent what the 10-K says and ask it to find the cause and fix the program. The usual cause is that the program attached numbers to the wrong year, because each 10-K also reports the two years before it. A table with fewer than ten years can still be correct; Uber, for example, has filed with the SEC only since its 2019 IPO.

Other projects

For a project of your own, make a new folder with the files the agent needs, then describe the result you want. Choose something a chat window cannot do, such as working through a whole folder of your files or downloading the data a program needs.

Ask the agent for a plan before it writes any code, and check one result by hand when it finishes.

Typing python opens the Microsoft Store Search the Start menu for Manage app execution aliases and turn off the two Python entries.

The Claude installer says another installation is in progress Right-click the installer and choose Run as administrator.

macOS asks whether the app may access your Desktop folder (Codex may also ask about Downloads and Music) Allow Desktop, which holds your folder. You can decline the others.
A window asks to install the command line developer tools Click Install and wait for it to finish (it can take ten minutes), then repeat your request. These are Apple's free developer tools, which agents use.
CERTIFICATE_VERIFY_FAILED when the program downloads Open Applications, then the Python folder, and double-click Install Certificates.command. Then ask the agent to run the program again.
The ChatGPT app will not install on an Intel Mac OpenAI's instructions name only Apple Silicon. Use Antigravity, which has an Intel version.
PowerShell says that running scripts is disabled Open PowerShell from the Start menu, run Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser and answer Y.
You run out of free use Open the same folder in one of the other tools, where your files still are, and type: Read the files in this folder and finish the task.

For anything else, copy the full error message into the agent and ask it to explain the error and fix it.

Precautions

Keep each project in its own folder, and open only that folder in the agent. Never paste a password into the agent, and keep files you may not share, such as licensed course cases, out of the folder. If you subscribe to a paid plan only for this, set a reminder to cancel it.
